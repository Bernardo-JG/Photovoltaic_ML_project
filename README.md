## Overview
This project aims to explore Machine Learning (ML) models to predict the efficiency of photovoltaic (PV) modules and classify the efficiency into four levels: "Extremely Bad", "Bad", "Moderate", and "Good". The project compares traditional ML models with Deep Learning (DL) models.

## Dataset
We used the "PV Module Efficiency dataset" (`pv_module_efficiency_dataset.csv`).

## Project Structure
- `data/`: Contains the datasets.
  - `raw/`: Raw, unprocessed data.
  - `processed/`: Data that has been preprocessed.
- `notebooks/`: Contains all Jupyter notebooks.
  - `data_preprocessing.ipynb`: Notebook for data cleaning and preprocessing.
  - `exploratory_data_analysis.ipynb`: Notebook for exploratory data analysis.
  - `feature_engineering`: Notebook for engineering (combination, deltion) of features.
  - `model_training.ipynb`: Notebook for training different ML and DL models.
  - `model_evaluation.ipynb`: Notebook for evaluating the models.
  - `cross_validation.ipynb`: Notebook for K-Fold Cross-Validation.
- `scripts/`: auxiliary Python scripts.
  - `data_cleaning.py`: Script for data cleaning.
  - `feature_engineering.py`: Script for feature engineering.
  - `model_utils.py`: Utility functions for training and evaluating models.
- `docs/`: Contains project documentation.
  - `references.md`: List of references and scientific papers used.
  - `methodology.md`: Detailed description of the methodology applied.
  - `results.md`: Discussions and conclusions about the obtained results.
- `results/`: Contains results generated by the models.
  - `figures/`: Plots generated during analysis and model evaluation.
  - `metrics/`: Files with performance metrics of the models.
